## Brand & Style

This design system establishes a high-trust, premium academic-tech ecosystem engineered specifically for modern universities, colleges, and research campuses. Navigating loss or discovery on campus often triggers high emotional friction: anxiety, urgency, disruption, or vulnerability. The design language directly counters this stress by projecting calm authority, institutional safety, and high-velocity clarity.

The visual direction marries high-end SaaS software elegance with approachable, student-friendly clarity:
- **Tone:** Methodical, hyper-credible, proactive, and effortless.
- **Visual Personality:** A seamless union of clean institutional prestige (deep royal/navy tones) and cutting-edge software craft (diffuse tinted ambient illumination, frosted glass nav layers, pristine pill micro-elements, and crisp geometry).
- **Aesthetic Principles:** Structured information hierarchy, airy multi-layer elevation, high-contrast action triggers, and purposeful tactile feedback.

## Colors

The color architecture utilizes chromatic precision to guide students and campus administrators toward rapid resolution while reinforcing security:

- **Primary (`#1266E8` - Royal Blue):** The primary brand anchor. Used for primary CTAs ("I Lost Something"), active state indicators, critical action triggers, and active focus outlines.
- **Secondary (`#081B43` - Navy Dark):** The institutional bedrock. Used for top-level headers, the prominent navigation bar background (or high-contrast header elements), brand wordmarks, and dark surface overlays.
- **Tertiary Accent (`#2998FF` - Electric Blue):** Vibrant accelerator. Used for match notification pings, hover highlights, step numbers, subtle progress indicators, and luminous glow accents.
- **Neutral Dark / Deep Text (`#101B35`):** High-density ink tone. Guarantees high-contrast readability across all display tiers, standard typography, and core data readouts.
- **Secondary Neutral Text (`#65738B`):** Neutral slate tone for metadata, helper text, timestamps, item location descriptors, and structural labels.
- **Surface & Backgrounds:**
  - Base Canvas: `#FFFFFF` (Pure White).
  - Pale Surface Highlight: `#EAF3FF` (Ice Blue Tint). Used for low-friction secondary actions ("I Found Something"), verified claim badge fills, interactive card backgrounds, and active state highlights.
  - Border Subtle: `#E2E8F0`. Restrained hair-line structural dividers, card contours, and input boundaries.

## Typography

The type system is anchored on **Plus Jakarta Sans**, chosen for its geometric precision, contemporary tech presence, and legible letterforms.

- **Display & Headlines:** Heavyweight (`700` and `800`) scales with negative letter spacing (`-0.01em` to `-0.03em`) to create dense, impactful editorial headers that establish authority.
- **Body:** Open counters and clean geometric x-heights set at `400` weight ensure fatigue-free reading across incident logs, property descriptions, and instructional steps.
- **Labels & Micro-copy:** Uppercase and title-cased labels are tracked slightly wider (`0.02em` to `0.04em`) at `600` and `700` weights to guarantee instant legibility in high-pressure recovery tasks.

## Layout & Spacing

This design system uses a 12-column responsive fluid grid structured around an 8pt architectural rhythm, with a strict maximum container width of `1280px` for optimal reading tracking and horizontal balance.

- **Breakpoints:**
  - **Desktop:** `1200px+` (12 columns, `1.5rem` / `24px` gutter, `2rem` / `32px` margin).
  - **Tablet:** `768px - 1199px` (8 columns, `1.25rem` / `20px` gutter, `1.5rem` / `24px` margin).
  - **Mobile:** `< 768px` (4 columns, `1rem` / `16px` gutter, `1rem` / `16px` margin).

- **Vertical Rhythm:**
  - Hero sections maintain generous breathing room (`4rem` to `6rem` vertical padding).
  - Content sections (e.g., How It Works, Trust & Safety) use structured `5rem` spacing on desktop, collapsing to `3rem` on mobile.
  - Component card padding defaults to `space-lg` (`1.5rem`), scaling down to `space-md` (`1rem`) on small viewports.

## Elevation & Depth

Visual hierarchy relies on multi-layered depth, subtle glassmorphism, and colored ambient shadows rather than harsh drop shadows.

- **Level 0 (Flat / Canvas):** Surface color `#FFFFFF` with hairline outline `1px solid #E2E8F0`. Used for data rows and baseline containers.
- **Level 1 (Subtle Elevation):** `box-shadow: 0 1px 3px 0 rgba(8, 27, 67, 0.04), 0 4px 12px 0 rgba(8, 27, 67, 0.03);` with `1px solid #E2E8F0`. Used for standard content cards and input fields.
- **Level 2 (Floating Feature Cards):** `box-shadow: 0 4px 16px -2px rgba(8, 27, 67, 0.06), 0 12px 32px -4px rgba(18, 102, 232, 0.08);` with `1px solid rgba(226, 232, 240, 0.8)`. Used for active listings, claim previews, and interactive cards.
- **Level 3 (Modal / Floating Utility / Hero Accents):** `box-shadow: 0 20px 48px -8px rgba(8, 27, 67, 0.16), 0 10px 24px -4px rgba(41, 152, 255, 0.12);`. Used for floating hero visual artifacts, magnifying lens graphics, and dialogue modals.
- **Glassmorphic Tiers:**
  - Navigation bar and pinned sticky headers use `backdrop-filter: blur(16px); background: rgba(255, 255, 255, 0.88); border-bottom: 1px solid rgba(226, 232, 240, 0.8);`.

## Shapes

The platform adopts a structured, modern rounded design language:
- **Base Components:** Radius `0.5rem` (`8px`) for compact UI elements, text fields, and standard badges.
- **Card Containers:** Radius `1rem` (`16px`) for primary cards, feature pods, and step containers.
- **Interactive Pill Elements:** Fully rounded radius (`9999px`) reserved specifically for action buttons, verification pills, category filters, and status markers to introduce an energetic visual rhythm against orthogonal card grids.

## Components

### Brand Navigation & Wordmark
- **LostLink Identity:** Custom wordmark typography set in `Plus Jakarta Sans` ExtraBold (`#081B43`).
  - The counter of the first **'O'** embeds a micro GPS coordinate pin crafted in Royal Blue (`#1266E8`).
  - The dot of the **'I'** transitions into a micro magnifying glass handle angled at 45 degrees in Electric Blue (`#2998FF`).
- **Bar Architecture:** Floating pill or fixed glassmorphic banner (`backdrop-blur-md`, white at 88% opacity, subtle bottom border `#E2E8F0`). Right-aligned campus selector dropdown and student portal authentication link.

### Action Triggers (Dual Hero CTAs)
- **Primary CTA ("I Lost Something"):**
  - High-impact button with fill `#1266E8`, text `#FFFFFF`, rounded pill (`9999px`), padding `1rem 2rem`.
  - Ambient elevation glow on hover: `box-shadow: 0 8px 24px rgba(18, 102, 232, 0.35); translateY(-2px);`.
- **Secondary CTA ("I Found Something"):**
  - High-contrast balance button with fill `#EAF3FF`, text `#1266E8`, border `1px solid rgba(18, 102, 232, 0.2)`, rounded pill (`9999px`), padding `1rem 2rem`.
  - Hover state: background transitions to `#D8E9FF` with `translateY(-2px);`.

### 3D Floating Visual Motif (Hero Accents)
- **3D Magnifying Glass & Asset Render:** Visual accent positioned in the hero's right grid. Characterized by a thick glass lens (`backdrop-filter: blur(8px)` with high-refraction gradient borders), capturing miniature floating 3D campus artifacts (AirPods, student ID badges, water bottles, keys) within an ambient Electric Blue (`#2998FF`) volumetric field.

### Feature Floating Cards
- Elevated cards (Elevation Level 2) with subtle `#FFFFFF` backgrounds and soft `#E2E8F0` borders.
- Include live status ribbons, relative timestamps (e.g., "Found 12m ago near Library West"), high-resolution category chips, and geo-tagged room identifiers.

### 4-Step 'How It Works' Flow
- Linear card sequence organized into 4 logical phases:
  1. **Report:** Smart tagging with rapid photo-upload and location metadata.
  2. **Match:** Automated visual & text matching algorithm against campus log.
  3. **Verify:** Proof-of-ownership security questions and student ID validation.
  4. **Return:** Secure locker exchange or Campus Security desk retrieval.
- Each step features a numeric step badge with `#EAF3FF` background, `#1266E8` bold text, and a directional gradient trail.

### Verified Claim Badges & Chips
- **Badges:** Pill-shaped indicators (`padding: 0.25rem 0.75rem; font-size: 11px; font-weight: 700;`).
  - *Verified Claim:* Background `#EAF3FF`, text `#1266E8`, icon checkmark with a `1px solid rgba(18, 102, 232, 0.3)`.
  - *Pending Campus Audit:* Background `#FFF7ED`, text `#C2410C`.
  - *Returned:* Background `#ECFDF5`, text `#047857`.

### Trust & Safety Grid
- A 3-column structured grid demonstrating privacy controls:
  - FERPA-compliant student data masking.
  - Campus Police & Facility Services verified exchange hubs.
  - Blind serial number verification for high-value tech.
- Cards use minimalist pure white backgrounds with `#EAF3FF` icon containers and `#65738B` descriptive text.

### Form Inputs & Checkboxes
- **Inputs:** `48px` height, border `1px solid #E2E8F0`, rounded `8px`, font size `15px`, placeholder text `#65738B`. Active focus state features `border-color: #1266E8` and `box-shadow: 0 0 0 3px rgba(18, 102, 232, 0.15)`.
- **Checkboxes & Radios:** Custom `20px` squares/circles with `2px solid #E2E8F0`. Checked state: `#1266E8` background with crisp white check glyph.

### Footer
- Deep institutional ground `#081B43` with clean white typography (`#FFFFFF`) and slate secondary links (`#65738B`).
- Hosts university partner directory, campus safety dispatch hotline, privacy policies, and an interactive real-time platform system status indicator.
